API Endpoints

The following API endpoints are available for programmatic access:

  • GET /api/stats/ - Get database statistics
  • GET /api/export/ - Export all polls data
  • POST /api/import/ - Import polls data (JSON body)
  • POST /api/reset-votes/ - Reset all vote counts

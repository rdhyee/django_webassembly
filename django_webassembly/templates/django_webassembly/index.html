Django WebAssembly v0.2.0

Welcome to Django running entirely in your browser via WebAssembly. There is no server - everything runs client-side using Python compiled to WebAssembly.

How it works

This application uses Pyodide to run Python in the browser, with a Service Worker intercepting all HTTP requests and routing them through Django's WSGI application. Your data is stored locally in an SQLite database in your browser.
